# B2B Marketplace Demo

This is a simplified B2B marketplace demo built with core PHP and MySQL. It includes supplier and buyer modules, enquiries with basic chat, and an admin panel for approving products and managing categories.

## Setup
1. Create a MySQL database named `marketplace`.
2. Import `database.sql` to create tables and sample data.
3. Place the project in your web server's document root.
4. Access the site via `index.php`.
